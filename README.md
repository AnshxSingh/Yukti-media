# Yukti Media — Next.js 3D Web Application

A high-performance modern web application for **Yukti Media**, built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **shadcn UI** conventions.

## 🚀 Key Features

- **Dynamic Inversion Circle Scroll Hero**: Scroll-driven dual-phase color-inversion lens animation with 3D logo floating in Three.js (isometric top-right tilt).
- **Interactive 3D Computer Screen Showcase**: 3D Apple Silver monitor (`Computer Screen.glb`) displaying project websites with dynamic crossfades and isolated parallax hover effects.
- **Client Video Reels**: High-retention video showcase with individual volume mute/unmute controls.
- **Performance Analytics Dashboard**: Live metrics cards tracking viewership growth and client satisfaction.
- **Responsive Navigation & Action Center**: Sticky header with mobile menu drawer and direct WhatsApp / Email booking channels.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics & WebGL**: [Three.js](https://threejs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for production
```bash
npm run build
npm run start
```
